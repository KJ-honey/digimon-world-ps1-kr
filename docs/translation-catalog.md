# 지명·아이템·디지몬 이름 번역 관리

2026-09-28 사용자 요청으로 대사 외 문자열을 검수기에 포함했다.
기준 ISO와 통합 테스트 이미지는 [current.md](current.md)의 것을 유지한다.

```sh
python3 tools/translation_review.py prepare-catalog
python3 tools/translation_review.py serve --open
```

검수 화면의 **문자열 종류**에서 지명·아이템명·아이템 설명·디지몬 이름을 고른다.
원문/기존 번역 대조, 직접 편집, 메모, 초안 저장, 문구 승인/보류, revision과 변경 이력,
통합 백업을 지원한다. 기존 대사 4,617개와 신규 506개를 함께 관리한다.
새 항목은 문구 작성 전이며 기존 번역을 편집 시작점으로 보여준다.
이 단계에서 ISO는 변경하지 않았다.

| 종류 | 슬롯 수 | EXE 논리 파일 위치 | 구조 |
| --- | ---: | --- | --- |
| 지명 | 70 | `0xA5304` | 4-byte RAM 포인터 |
| 아이템명 | 128 | `0xA2D60` | 32-byte record의 앞쪽 문자열 |
| 아이템 설명 | 128 | `0xA3D60` | 4-byte RAM 포인터 |
| 디지몬 이름 | 180 | `0xAA924` | 52-byte record의 앞쪽 문자열 |

디지몬 이름 수는 고유 종족 수가 아니다. 동명 레코드, 고정 `주인공`/`디지몬` 라벨도
포함한다. 예: `digimon_name-003`은 `アグモン`/`아구몬`, `location_name-043`은
`はじまりの街`/`시작의　마을`이다. 사용자 입력 주인공/파트너 이름 버퍼와 별개다.

`tools/translation_catalog.py`의 선언된 테이블 경계와 MIPS 소비자 해시를 두 원본에서
검사한다. 지명은 맵 record의 인덱스 → 포인터 → 일반 렌더러,
아이템명과 디지몬 이름은 인덱스 × stride → 문자열 복사/길이 소비자,
아이템 설명은 인벤토리 아이템 ID → 포인터 → 일반 렌더러 경로를 확인했다.
정적 소비자 증거이며 개별 항목이 실제 플레이에서 등장했다는 증거는 아니다.

각 판의 포인터를 따로 따라가며 원문과 번역의 시작점/길이가 같다고 가정하지 않는다.
포인터의 RAM 주소와 EXE 논리 파일 offset을 별도 필드로 기록한다.
일반 렌더러의 byte NUL 종료와 2-byte 글리프 진행을 따르며 DG 종료코드는 붙이지 않는다.
미확정 글리프/중복 코드 별칭은 `⟦G:XXXX⟧`로 보존한다. 양쪽 506개의 Unicode 왕복을
원본 payload와 대조했다. 같은 문자열/같은 포인터라도 인덱스별 ID를 유지한다.

- `work/translation/catalog/baseline.json`: 추출 원문·기존문·raw bytes·참조/문자열 위치·소비자 근거. Git 제외.
- `work/translation/catalog/reviews.json`: 작성 문구와 검수 이력. Git 보존.
- `work/translation/catalog/history/`: 테이블 추가 전 기준/이력 백업. Git 제외.

기존 DG baseline/reviews 해시와 항목 이력은 바꾸지 않는다. 새 종류 추가 시에도 기존
항목과 입력 해시가 전부 같을 때만 기준 목록을 확장하고 작성 결정을 보존한다.
기존 항목 변경이나 삭제는 자동 갱신을 거부한다. 저장 잠금과 오래된 revision 거부는
대사와 동일하다. 제품 DG exporter는 원래 대사 저장소만 소비한다.

이름·설명에는 DG 제어코드/줄바꿈을 허용하지 않으며 미확정 글리프 삭제도 거부한다.
초안 길이는 원래 슬롯 크기로 제한하지 않는다. 일반 렌더러의 글자 간격은 대사와 다르므로
6px 공백·252px 폭을 여기에 적용하지 않는다. 실제 인코딩, 확장 공간, 공유 포인터 처리,
전체 참조, 화면별 표시 폭 및 게임 장면 검증을 거쳐 별도 삽입 경로를 구현해야 한다.
문구 승인은 이 조건들의 통과를 의미하지 않는다.

카드·기술·곡·대회명과 기타 UI/overlay 문자열도 관리 범위에 속하지만 아직 미추출이다.
전체 게임 번역량/추출 완료로 보고하지 않는다. 후속 문구 검수에서는 대사 속 표현과
지명·아이템·디지몬 테이블의 명칭 일관성을 함께 확인해야 한다.
