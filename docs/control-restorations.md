# 원문 제어코드 복원과 줄 배치

2026-09-28 사용자가 남은 제어코드 차이 9개를 가볍게 대조해 안전한 경우 반영하고,
넘치는 문장은 줄바꿈으로 수정하도록 지시했다.

| 리뷰 ID | 원본 DG 본문 offset | 기존 한국어판에서 빠진 내용 |
| --- | --- | --- |
| `dg-text-01e28e` | `0x01E290` | 화자명 색상 `0107`과 복귀 `0101` |
| `dg-text-01e2d0` | `0x01E2D2` | 화자명 색상과 복귀 |
| `dg-text-036110` | `0x036112` | 화자명 색상과 복귀 |
| `dg-text-036192` | `0x036194` | 화자명 색상과 복귀 |
| `dg-text-0365e8` | `0x0365EA` | 화자명 색상과 복귀 |
| `dg-text-03e106` | `0x03E108` | 화자명 색상과 복귀 |
| `dg-text-063b2c` | `0x063B2E` | 주인공 이름 `0500` 및 색상 `0106`/`0101` |
| `dg-text-06f8a2` | `0x06F8A4` | 버튼 glyph `8283` 및 색상 `0104`/`0101` |
| `dg-text-096f02` | `0x096F04` | 주인공 이름 및 색상 |

주소는 원본 `SCN/DG.SCN` 논리 파일 offset이다. 명령 헤더 `1A00`는 각각 2 bytes 앞에
있다. ISO raw-sector 주소나 RAM 주소가 아니다. 확장 DG 파일의 원래 스크립트 구간은
`+0x1800` 이동하며, 변경 payload는 별도 bank에 들어가므로 위 주소를 새 이미지에
그대로 적용하면 안 된다.

9개 모두 일본어 원문의 제어/버튼 구성을 확인했다. `dg_control_restorations.py`의
허용 목록은 항목 ID, 기존 한국어 payload 전체 SHA-256, 복원할 보호 토큰열을 묶는다.
일반 항목의 보호 검사는 그대로이며, 임의 제어 추가·삭제·색상/이름/버튼 교체를 허용하지 않는다.
원문 대비 줄바꿈 변경은 아래에서 사용자 지시로 정리한 배치만 추가 허용한다.

- `03e106`: 화자명 뒤 대사를 3줄로 나눠 총 4줄로 구성했다.
- `06f8a2`: 구매 가능 수량 전체 선택, 버튼을 누른 상태의 방향키 조작, 10개 단위 증감을
  유지하면서 4줄로 정리했다. 기존 3줄 초안은 64-byte 버퍼를 초과했다.
- `096f02`: 이름 뒤 문장을 다음 줄로 넘겨 6글자 이름일 때의 잘림을 해소했다.

이 세 항목만 `Workspace.save`로 revision 이력과 함께 저장했다. 번역 승인 상태를
새 승인으로 바꾸지 않았다. 기존 64-byte 검사 외에 이 복원 항목들은 실제 글리프
시작 X<244 제한도 검사한다. 전각 12px, 반칸 6px, 이름 최대 6글자를 합산한다.

현재 리뷰 전체의 새 빌드 입력은
`work/translation-playtest/control-restorations-001/selected/edits.json`이다.
4,617개 모두 선택되며 변경 4,421개, 원본 동일 196개, 검사상 보류 0개다.
백업·3개 수정안·CPU 대조는 같은 폴더 상위의 `reviews-before.json`, `reflow.json`,
`verification.json`에 있다. 원래 소비자와 행 렌더러의 CPU 실행으로 9개 출력 행과
글자 좌표를 검사했으며 BIOS 문자열 함수와 GPU는 stub이다. 실제 9개 장면의 게임
표시 또는 전체 게임 검증을 뜻하지 않는다. 최대 행 예산은 48/64 bytes이며,
마지막 글리프 우측 끝은 최대 252px다. 자동 테스트 66개가 통과했다.
ISO는 이번에 재생성하지 않았다.

후속 사용자 빌드 요청으로 `work/build/control-restorations-001/dg-expanded.cue`를 생성했다.
전체 4,617개 선택, 보류 0개이며, 이미지 무결성·재추출 및 변경 4,421개 소비자 CPU 검증을
통과했다. 최종 이미지 해시와 한계는 `docs/current.md` 및 빌드 폴더의 `verification.json` 참조.
